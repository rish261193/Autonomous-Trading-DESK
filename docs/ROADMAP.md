# Build Roadmap

## Phase 0 — Repository foundation (current)
Documentation, deterministic risk tests, configuration templates, research and audit schemas. No brokerage credentials.

## Phase 1 — Research Lab
Acquire reproducible BTC/ETH historical data, implement strategy representation and candidate generation, screen variants, model fees, and run out-of-sample tests. Benchmark VectorBT/Freqtrade/Optuna and evaluate Wendy.

## Phase 2 — Paper desk
Connect a compatible paper broker; implement data freshness checks, authorized strategy registry, deterministic risk gateway, execution and fill reconciliation, daily P&L and alerts.

## Phase 3 — Eleven-agent orchestration
Add event-driven agent research, bull/bear challenge, portfolio selection, audit and WhatsApp relationship management. Avoid 11 LLM calls per market tick.

## Phase 4 — Evidence and commercialization decision
Evaluate net returns, drawdown, execution quality, reproducibility, operating costs, and regime robustness. Assess brokerage availability, regulations, customer demand and subscription economics before live trading or selling automated execution.

## Budget
Initial incremental experiment target $30 excluding existing ChatGPT subscription; API, hosting, messaging, and data costs must be explicitly tracked. Cloud costs are not assumed to be zero.
